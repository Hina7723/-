# 
自分の筋トレ、英語、感じたことなどを記録する。

## 背景（なぜ作ったか）
- 年内の起業に向けて、日々の行動と気づきを蓄積したかった
- 日記は記録そのものより、振り返って次の一歩を設計する材料として使いたい
- 夜のスケジュールタスク `nightly-diary` と同じ動きを、どのチャットからでも再現できるようにしてある

## できること
- 出来事・調子・学び・起業ログ・明日の ToDo を、1問ずつ聞き取って日記にする
- うまく言語化できた発言は、整えずに「そのままの言葉」欄に残す
- 末尾に、前進した点・停滞した点・次の一歩のフィードバックを付ける
- 本人が「ログに書いて」と言ったときだけ、読書記録・映画ログに1行追記する

## 言い方の例
- 「「日記」「日記書く」「今日の日記」」
- 「「日記 短め」」
- 「「振り返り」」

## 使い方の流れ
1. 前日の日記がなければ、昨日の分も書くか聞かれる
2. 1問ずつ答える（短め版は、出来事・調子・明日やること、の3つだけ）
3. 下書きが出る。承認すると、`日記/YYYY-MM-DD週/` に保存される

## 注意点
- 文体は敬語で、感嘆符・絵文字は使わない。本人が言っていないことは書かない（ハルシネーション禁止）
- 空虚な称賛をせず、記録に基づいて客観的に評価する
- 承認なしに書き込まない
- 週次・月次のレビューは別のルーチンの担当。このスキルは日次の日記
